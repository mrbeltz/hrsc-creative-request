# HRSC Creative Request

A guided request form for the Harrah's Resort Southern California Advertising team. Requesters describe what they need. The form matches the request to the right FunctionPoint request templates, asks for the details each template requires, and sends the request to Zapier, which creates Draft briefs in FunctionPoint.

- Live page: served from `index.html` by GitHub Pages.
- Settings: the `CONFIG` block near the top of the script in `index.html` (webhook URL, file upload link, contact email, allowed email domains, hold threshold).
- Submissions are accepted only from @caesars.com and @harrahs.com addresses.
